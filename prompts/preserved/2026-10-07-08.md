## What to find

**Over-engineered:** an interface or abstraction with one implementation and no test double; dead code (no caller in `main/`; check reachability with `git grep` first, per CLAUDE.md); constants or settings nothing varies; the same thing done two or three ways; comments far out of proportion to the code; tests that assert wiring rather than behaviour; machinery defined and unused (for example the motion tokens and `LocalReduceMotion` the motion scout found).

**Under-engineered:** swallowed exceptions or fallbacks that aren't logged (CLAUDE.md "Errors and failure paths"); very large files or functions doing many jobs; important behaviour with thin or no tests; hand-copied logic; breaches of CLAUDE.md's architecture rules (domain logic with Android UI bindings; vendor SDKs or HTTP used directly, not behind an interface Forager owns; reported device ranges used without an operating limit); missing error handling on network, location, camera and storage.

Cover the whole app: map and its chrome; journal, records and finds; recording, navigation and the alerts; data (Room, DataStore, backup, import and export); the List, Seasonal, search, Settings, Tools and camera; build and dependency setup.
