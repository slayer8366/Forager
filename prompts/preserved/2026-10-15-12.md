## What to build

### Part 1: watch mode through CameraX

The dialog's own camera, so it reflects what Forager's users get.

A debug toggle, adb broadcast on/off, that logs one JSON line per preview capture result, rate-limited to at most 5 lines a second, plus one for every still capture. Each line carries:
- `LOGICAL_MULTI_CAMERA_ACTIVE_PHYSICAL_ID`;
- the zoom ratio in effect;
- lens focus distance and AF state;
- exposure time and ISO;
- the scene brightness estimate if available;
- the sensor timestamp.

When the active physical ID changes, also log a `switch` line with from, to, and what changed (zoom, focus distance, exposure).

Use the interop session capture callback that stage 2 uses, kept inside the debug source set if it can be. If the main code must expose a hook, that is a stop-and-ask: report it, don't change main.

### Part 2: the zoom stepper

An adb broadcast that sets the dialog camera's zoom ratio to a given value, for example `--ef ratio 0.6`, clamped to the camera's reported zoom range and logged as clamped.

- Use CameraX's `setZoomRatio`, the standard API.
- No on-screen control.
- A second broadcast steps through a list, holding each step for a set time (default 3 s) so the log captures the settled sensor at each step: 0.6, 1, 1.5, 2, 2.9, 3, 3.1, 5, 9.9, 10, 10.1, 20, 30, 100, as far as the range allows.
- Afterwards it returns the zoom to 1.0.

### Part 3: pinning, through the platform interface

Borrow the camera as the fast-burst probe does, and try three ways of getting RAW from the main wide sensor only. Log for each whether it configured, the active physical ID on every frame, the RAW size and colour pattern, and any error:
1. **A physical stream on the logical camera.** Open logical 0 with an `OutputConfiguration` whose physical camera ID is set to the main wide's ID, read from characteristics and never hard-coded. Take one RAW frame and a short burst.
2. **The physical camera opened directly,** if `getCameraIdList` or `CameraManager` allows it. Report if it is refused.
3. **The logical camera at zoom 1.0 with no physical stream,** as a control.

Hand back as before.
