## Change

1. **The offline-maps download screen, in both orientations.** The confirmed step path:

   > Records → Offline maps → pan the map to place the pin → (optional) name it and set the radius → tap **Download Maps** → the existing "Download this area?" confirmation → it downloads. **No OK and no Cancel buttons.** Back leaves the screen, as Cancel did.

   - Download Maps uses wherever the pin sits now. It is enabled whenever the map has a position and no download is running, and is never greyed waiting for OK.
   - The confirmation dialog is unchanged.
   - In landscape, the pinned bottom becomes "Pin at: …", then Download Maps (full width).

   This is the offline-maps screen only. Every other picker that shares `CentrePinConfirmActions` keeps its OK and Cancel; if removing them here needs a parameter, it defaults to today's behaviour.
2. **The landscape pill is the right size from the first moment** (Elder item 2). On List, Seasonal and Journal in landscape, the pill uses Maps' size even before Maps has been shown in that window. Work it out from the window, as Maps' own pill does, instead of waiting for `lastMapsStripWidth`. Switching to Maps afterwards moves nothing and resizes nothing. Its size also survives a process restart in landscape.
3. **The search pill keeps its state across tab switches** (Elder item 4). The `key(compactTab())` around the AnimatedVisibility that holds `SearchEntryBar` recreates the bar on every tab switch, so the "no slide on arrival" behaviour has to be achieved another way. Focus and the field's internal state must survive a tab switch. The query already does; keep it.
4. **The known-bugs list** (`docs/process/known-bugs.md`, Elder item 3): update it for what this promotion ships, including:
   - row 3 as it stands;
   - the tablet camera's unmeasured smoothness at ROTATION_0, as an observation;
   - anything this dispatch leaves unfixed.

   One row per bug, in the list's own format.
