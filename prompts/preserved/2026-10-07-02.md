## The behaviour, as the owner confirmed it

- **Two ways in:**
  - Records > Tracks > **"Import GPX"** > Android's file picker > pick a .gpx file.
  - From Files, email or another app, **Open with** or **Share** a .gpx file > Forager is offered.
- Forager reads it, and it lands in Records as a track:
  - named from the GPX's own name, or the file's name if it has none;
  - with its line drawing, distance, and dates when the file has times;
  - with an **"Imported"** label, so it's never mistaken for a recorded walk.
- Waypoints in the file come with it, tied to that track like T10's: dots on the drawing, and the "Waypoints on this track" list.
- The track's map bubble > Details works as for any track.
- A file with several tracks: **each becomes its own track**, the file's loose waypoints go with the first, and a short note says "Imported 3 tracks".
- A file Forager can't read: **"This file couldn't be read as GPX"**.
