## The crash

The owner: "App force closes when trying to start". On the S26, build 1.0.3086+g0e766d94 (installed 11:36 PDT), the crash buffer shows:

```
java.lang.VerifyError: Verifier rejected class com.zynergylabs.forager.app.ui.availability.AvailabilityCompactMapUiKt: void ...CompactMapTab-ztWZzuM(<77 parameters …>, Composer, int ×10) failed to verify: ... [0x10E] register v0 has type Reference: com.zynergylabs.forager.app.ui.map.MapMode but expected Integer
  at AvailabilityScreenKt.AvailabilityScreen(AvailabilityScreen.kt:971)
```

ART rejects the class at load, so the app can't start. Robolectric runs on the JVM and doesn't verify like ART, which is why the 4,454-test suite and CI were green. `CompactMapTab` has about 77 parameters plus ten `$changed`/`$default` ints. The likely cause is a codegen or dex problem at that parameter count, introduced by one of today's added parameters (the cluster placement and basemap work in PR #201, the landscape join in #203, or another). This is inferred and not confirmed.
