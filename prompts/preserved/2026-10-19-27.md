## Change

A script `scripts/s22-screenshot-set.sh` (on a branch, PR into pre-main as a draft) that, given an output folder **outside every repository**:
1. checks the device is the S22 and the app is installed, and prints the installed versionName;
2. drives the app by adb to a fixed list of screens: Maps tab, map fullscreen, search open, Tools drawer, Settings, Journal, List, Seasonal; and in each orientation (portrait, then landscape by `settings put system user_rotation` with auto-rotate off, restored afterwards to what it was);
3. saves one PNG per screen and orientation, named by screen, orientation and versionName, and a small text index;
4. never taps anything that records, deletes, downloads, shares or changes a setting, and never starts navigation;
5. fails loudly (non-zero exit, a message naming the step) if a screen can't be reached, rather than saving a wrong picture.

Navigation by adb taps at fixed coordinates is fragile: prefer reaching screens through accessibility node text or content descriptions (`uiautomator dump`) where the app exposes them, and say in the report which screens rely on coordinates.

## Proof

## Stops

Anything that would change the phone's data or settings beyond rotation (restored); a screen that can only be reached by a risky tap.
