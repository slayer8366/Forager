## The contract

**Package `com.zynergylabs.forager.app.domain.raw`** holds the types below: plain Kotlin, no Android imports.
- Names are binding. Add fields only as nullable, defaulting to null, and report each one.

```kotlin
enum class CfaPattern { RGGB, GRBG, GBRG, BGGR }

data class URational(val numerator: Long, val denominator: Long)
data class SRational(val numerator: Int, val denominator: Int)

/** One illuminant's calibration, as the camera reports it. Matrices are row-major, 3x3. */
data class DngCalibration(
    val illuminant: Int,                       // EXIF LightSource code, e.g. 21 = D65, 17 = Standard A
    val colorMatrix: List<SRational>,          // required, 9 values
    val forwardMatrix: List<SRational>? = null,
    val cameraCalibration: List<SRational>? = null,
)

/** Per-colour-channel gain grid, in the camera's lens-shading-map layout (R, Geven, Godd, B). */
data class LensShadingMap(val columns: Int, val rows: Int, val gains: FloatArray)

data class DngImage(
    val width: Int,
    val height: Int,
    /** Row-major, one sample per pixel, unsigned 16-bit in a ShortArray, low-justified as the sensor delivers it. */
    val samples: ShortArray,
    val cfa: CfaPattern,
    val blackLevel: List<Float>,               // 4 values, in CFA order
    val whiteLevel: Int,
    val activeArea: IntArray? = null,          // top, left, bottom, right
    val calibration1: DngCalibration,
    val calibration2: DngCalibration? = null,
    val asShotNeutral: List<URational>,        // 3 values
    val noiseProfile: List<Double>? = null,    // pairs (S, O) per CFA channel
    val lensShading: LensShadingMap? = null,
    val orientation: Int,                      // TIFF Orientation 1..8
    val baselineExposure: SRational? = null,
)

sealed interface DngWriteResult {
    data class Written(val bytes: Long) : DngWriteResult
    data class Failed(val reason: String) : DngWriteResult
}

interface DngWriter {
    /** Writes [image] to [destination], then re-reads it and checks it. On any failure the file is deleted and Failed returned. Never throws. */
    fun write(image: DngImage, destination: java.io.File): DngWriteResult
}
```

**The implementation:** `com.zynergylabs.forager.app.data.raw.ForagerDngWriter : DngWriter`, also free of Android imports, plus whatever internal classes it needs: a TIFF writer, a lossless encoder, a reader for the check.

## What to build

1. **A valid DNG 1.4 file:**
   - Uncompressed-thumbnail-free: IFD 0 is the raw image (NewSubFileType 0). No preview IFD is needed in this stage. If a common desktop raw editor needs one, report it.
   - Required tags: DNGVersion, DNGBackwardVersion, UniqueCameraModel "Forager", CFA tags (CFARepeatPatternDim, CFAPattern, CFAPlaneColor, CFALayout), BlackLevelRepeatDim and BlackLevel, WhiteLevel, the colour matrices and illuminants, AsShotNeutral, Orientation, and ActiveArea when given. Software, if written at all, is "Forager" with no version or device string.
   - NoiseProfile when given. The lens-shading map, when given, becomes an OpcodeList2 GainMap per CFA channel, per the DNG 1.4 specification.
2. **Lossless compression:**
   - Lossless JPEG (Compression 7) in tiles, as common desktop raw editors read it, unless you find a better-supported option. Say which, and why.
   - **Decoding must give back the input samples bit for bit.**
3. **The check after writing, failing closed:**
   - Re-parse the written file with our own reader.
   - Assert that no Make (271), Model (272), DateTime (306), DateTimeOriginal (36867), GPSInfo (34853) or any EXIF/GPS sub-IFD is present, and that UniqueCameraModel is "Forager".
   - Scan every ASCII, BYTE and UNDEFINED value (not pixel data) for a caller-given list of forbidden strings. The camera side passes the phone's make, model, brand and build fingerprint.
   - Failure means: delete the file and return Failed with the cause.
   - So `write` takes the forbidden strings too. **This is the one contract addition expected:** a constructor parameter `forbiddenStrings: List<String>` on `ForagerDngWriter`, leaving the interface as written.
4. **Operating limit:** refuse, with Failed, an image above 12.6 MP or with dimensions or array sizes that don't match. Never write a malformed file.

## Tests (tests first, each shown failing against a stub that writes nothing or returns Failed)

1. **Round trip:** write a synthetic 64×48 image in each CFA phase. Re-read it with our reader and with an independent decode of the lossless stream, and get the identical samples. Use both byte orders if the writer offers both; otherwise little-endian only, stated.
2. **Required tags:** every required tag is present with the given value; UniqueCameraModel is "Forager".
3. **Forbidden tags:** none is ever written, whatever the input.
4. **The check fails closed:** a planted Make tag, a planted GPS IFD, and a planted forbidden string in an ASCII tag each make `write` return Failed and leave no file. Test through a test-only hook that corrupts the bytes before the check.
5. **Calibration round trip:** matrices, illuminants, NoiseProfile and GainMap values read back as given.
6. **Limits:** an oversized image, or one whose array length doesn't match its dimensions, gives Failed and no file.
