## Build

A new workflow file, separate from ci.yml.
- **Trigger:** `workflow_dispatch` only. The job declares `environment: release`, so it waits for the owner's approval and runs only on main.
- **Steps:**
  1. Decode the keystore to a file in `$RUNNER_TEMP` with umask 077.
  2. Set `FORAGER_SIGNING_STORE_FILE`.
  3. Run `./gradlew bundleRelease` with the existing release checks. The routing key guard must pass.
  4. Verify the bundle is signed by the upload key (print only the certificate fingerprint and compare it with the expected SHA-1/SHA-256 in an input or a committed constant from `forager-SHA.txt`, which the planner will supply).
  5. Upload to Play's **internal** track as a draft, through a well-known action or the Play Developer API, **pinned by full commit SHA**.
  6. Delete the keystore file in an `always()` step.
- **Never:** upload the AAB as a build artifact (the repo is public); echo a secret; enable `set -x`; run on pull_request.
